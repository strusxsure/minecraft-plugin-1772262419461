# WandSelector Plugin

A Minecraft Spigot/Paper plugin that opens a GUI when a player joins, allowing them to select one of three wands with special abilities.

## Features

- **Fire Wand**: Burns enemies on hit
- **Ice Wand**: Slows enemies on hit  
- **Lightning Wand**: Strikes lightning on hit
- GUI-based selection system
- Persistent wand selection per player
- Compatible with Spigot/Paper 1.20.1+

## Installation

1. Download the latest JAR file from the [Releases](https://github.com/yourusername/WandSelector/releases) page
2. Place the JAR file in your server's `plugins` folder
3. Restart your Minecraft server
4. Players will automatically see the wand selection GUI when they join

## Usage

### Selecting a Wand

When a player joins the server, a GUI titled "Select Your Wand" will automatically open. The GUI contains three options:

- **Fire Wand** (Slot 4): Burns enemies on hit
- **Ice Wand** (Slot 5): Slows enemies on hit  
- **Lightning Wand** (Slot 6): Strikes lightning on hit

Click on any wand to select it. The selected wand will be added to the player's inventory.
